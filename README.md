# 背包大师 · 在线试玩

《极限寻宝：背包大师》的可玩版本 —— 搜 → 摆 → 撤 → 卖。

**▶ 在线试玩：https://yunjihe.github.io/backpack-master-playtest/**

## 这是什么

- 微信小游戏方向的 **搜打撤 + 背包拼图** 原型：90 秒内搜刮战利品，把奇形怪状的物品塞进有限背包，在怪物扑上来之前撤离。
- 手机浏览器可直接玩，桌面浏览器也可以。
- 本仓库**只包含导出的单文件试玩页**（`index.html`），不含源码、设计文档或测试。源码在私有仓库中维护。

## 操作

| 操作 | 效果 |
|---|---|
| 拖动物品 | 从托盘拖进背包；绿色预览=能放，红色=塞不进 |
| 点一下物品 | 旋转 90° |
| 松手时自动转向 | 当前位置放不下但转一下能放时自动帮你转 |
| 滚轮 / 左右滑动托盘 | 查看后面的战利品 |
| 🧽 按钮 | 海绵模式，点击背包空格填缝 |

## 更新方式

试玩页由源码仓库的 `tools/export-pages.js` 导出后推送至此仓库，GitHub Pages 自动发布。构建产物请勿手工修改。
